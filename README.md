# Zapret Windows .bat to linux config
 Small convertor to convert windows .bat files into zapret configs

#### В этом репозитории нет:
**Оригинальных файлов из репозитория Zapret**
**Оригинальных файлов из репозитория Zapret discord youtube для windows**

### Для работы требуется:
Оригинальные .bat файлы из репозитория Zapret discord youtube,
**кроме:**
service.bat
general.bat

---

### Подготовка:
#### Клонируем репу и копируем файлы запуска в эту же директорию:
```
git clone https://github.com/SouceCalve/Zapret-Windows-.bat-to-linux-config
cd Zapret-Windows-.bat-to-linux-config
```
#### Запускаем:
```
python3 conv.py
```
#### На выходе у вас будет куча файлов в формате config<название_исходного_файла>, которые готовы к копированию в /opt/zapret
